# alx-low_level_programming

Low-level programming in C: exercises and projects from the ALX Africa Software Engineering programme, from Hello World to pointers, memory, linked lists, bit manipulation, file I/O, hash tables and search algorithms.

Coursework, kept as a record of the work. Each folder holds one project with its own README.
